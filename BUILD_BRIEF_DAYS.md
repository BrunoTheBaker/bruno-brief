# BUILD BRIEF — Multi-Day Scrolling Feed for "Bruno Brief" PWA

**Context:** Bruno Brief is a static PWA at /home/rory/Projects/news-pwa/ on GitHub Pages. Today it reads a single-day feed.json and renders story cards grouped by bucket, with an in-app deep-dive overlay. Rory wants:
1. **Twice the articles per day** (~12 stories/day instead of 6).
2. **A scrolling timeline across multiple days** — newest day at the TOP, older days below it, so he can scroll back through history over time.

## New data contract (train both the app and cron to this)

### feed.json — multi-day timeline (newest day FIRST)
```json
{
  "days": [
    {
      "date": "YYYY-MM-DD",
      "stories": [
        { "bucket": "<label>", "emoji": "<>", "headline": "<>",
          "summary": "<1-2 lines>", "sources": ["Src"], "slug": "<url-safe>" }
      ]
    }
  ]
}
```
- `days` is an array ordered newest-first. Each `days[i].date` is a distinct day (dates should be an unbroken or near-unbroken run, newest first).
- Stories stay grouped by bucket WITHIN a day.

### deepdives.json — keyed by date (prevents slug collision across days)
```json
{
  "deepdives": {
    "YYYY-MM-DD": {
      "<slug>": {
        "headline": "<>", "summary": "<>", "detail": "para1\n\npara2\n\npara3",
        "sources": ["Src"], "source_urls": ["https://..."], "updated": "YYYY-MM-DD"
      }
    }
  }
}
```
- The deep-dive for a story is looked up by BOTH its date AND its slug: `deepdives[date][slug]`.
